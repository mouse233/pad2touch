# Phase 1/2 统一实测清单

状态：**尚未执行**。日期：待用户有空时补记。以下“预期”不是已测结果。本轮静态开发没有开启真实注入或采集新触控板数据。

预计准备好后集中测试约 5–10 分钟。保持测试窗口可见、不移动；原生触控板鼠标和系统手势仍会同时发生。先测试单指，再测多指，最后检查退出。

## 准备

在项目目录打开普通 PowerShell：

```powershell
cargo build --release --locked
.\scripts\Run-PadBridge.ps1 -Mode probe
```

如果有多个设备，后续命令加 `-Device N`。注入只映射自身的固定接收矩形，没有任意目标窗口选择。

每次窗口出现后，先轻触再全部抬起一次，让程序收到空帧，从 `WAIT ALL FINGERS UP` 进入 `ARMED`。结束时脚本输出本次本地结果目录；日志不上传到 Git。

## 第一轮：单指 MVP

```powershell
.\scripts\Run-PadBridge.ps1 -Mode capture -Inject -Contacts 1 -Seconds 120
```

| 操作 | 预期 | 实际结果 |
|---|---|---|
| 手指放在板上时启动，再全部抬起 | 抬起前不产生新 DOWN，抬起后准备就绪 | 待测 |
| 四角、中心轻触 | 位置落在固定矩形相应位置，坐标不越界 | 待测 |
| 画圈、斜线、长距离拖动 | 轨迹连续，没有跳到其他手指 | 待测 |
| 长按 30 秒，保持不动 | 触点持续活动，UPDATE 保活，无意外取消 | 待测 |
| 抬手后空闲 3 秒，再次接触 | 正常开始新序列，无需额外重启 | 待测 |
| 快速连续轻点约 20 次 | DOWN/UP 配对，无卡住触点 | 待测 |
| 一指保持，放上另一指，再抬起原指 | 单指模式不跳到第二指；全部抬起后可以开始新序列 | 待测 |

结束后检查 `analysis.json`，正常测试应 `passed=true`，接收生命周期完整，summary 两端剩余触点为 0。

## 第二轮：同步多指

```powershell
.\scripts\Run-PadBridge.ps1 -Mode capture -Inject -Contacts 5 -Seconds 180
```

| 操作 | 预期 | 实际结果 |
|---|---|---|
| 两指同时移动、交叉方向移动 | 两条独立轨迹，ID 不串线、不合并 | 待测 |
| 两指捏合、展开 | 两指距离比变化，接收窗口演示方框随之缩放 | 待测 |
| 一指不动，另一指移动 | 静止手指持续活动，移动手指独立更新 | 待测 |
| 两指中抬起一指，另一指继续移动 | 只释放离开的手指，保留另一触点及 ID | 待测 |
| 保持一指、替换另一指，多次重复 | 新手指得到新生命周期，保留的手指 ID 不变 | 待测 |
| 三指、四指、五指分别同时接触并移动 | 接收活动数量跟随原始数量，峰值达到 5 | 待测 |
| 五指全部同时抬起 | 所有触点完成 UP，接收活动数量回到 0 | 待测 |
| 五指中替换一个触点，其余持续保持 | 保留触点无错误 UP；必要的容量拆帧后新触点正常开始 | 待测 |
| 重复两指/五指接触和抬起约 1 分钟 | 没有累计残留、参数错误或越来越多的延迟 | 待测 |

这里只验证自身接收窗口与原生触摸数据。第三方应用的缩放兼容性需要之后另行测试，不根据演示方框自动宣称通用兼容。

## 第三轮：结束时释放

```powershell
.\scripts\Run-PadBridge.ps1 -Mode capture -Inject -Contacts 5 -Seconds 30
```

放上两指并保持，按 Esc。预期先出现对应 UP，再关闭窗口；脚本正常返回，`injected_contacts_remaining=0`、`receiver_contacts_remaining=0`、`cleanup_pending=false`。再单独试一次计时结束时保持触点。不要用强制结束进程来替代正常退出测试。

窗口遮挡、最小化或移动属于暂停/取消场景，可能让日志校验报告运行错误；应人工检查是否已释放、是否等待空帧，并保留该次目录。不要把这类异常实验和要求零错误的正常轨迹测试混为一轮。

## 可选：区分输入问题与原生 API 问题

如果多指异常，可在不碰触控板时运行独立合成 API 对照：

```powershell
.\scripts\Run-PadBridge.ps1 -Mode self-test -Contacts 5 -Seconds 40
```

该命令会调用真实 InjectTouchInput，依次生成单指拖动、长按、快速轻点、两指捏合/展开、部分释放、替换及多指同时移动。界面和日志明确标为合成数据。通过只证明该运行中的 API 链路，不代替真实触控板验收。
